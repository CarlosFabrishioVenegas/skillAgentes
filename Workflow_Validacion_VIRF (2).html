Workflow de Validación — Copilot Studio

Un agente por prompt. Para cada paso: activa el agente indicado, carga los documentos listados y pega el prompt (ya trae tu bloque de anclaje). El prompt se especializa automáticamente según el tipo de modelo que elijas. Guarda el resultado con el nombre indicado y súbelo al paso siguiente.

1 · Datos del modelo (se llenan una vez)

Se inyectan en el anclaje de cada prompt. Es la defensa anti-alucinación: el agente vuelve a leer qué modelo es en cada turno.

Tipo de modelo (especializa el contexto de cada prompt)
0 / 12 pasos
    El bloque de anclaje se aplica en todos los pasos; el re-adjunto de A4_paso0.md aplica desde el Paso 5 (A4 lo genera en el Paso 4). En los Pasos 2, 3 y 4 se usa A1_entendimiento.md. El Paso 3 es el autodiagnóstico ITERATIVO (se repite ronda tras ronda hasta que el agente declara que no necesita más información) y el Paso 8 el motor de impactos monetarios. El contexto especializado se ajusta al tipo de modelo elegido. Cada paso EMITE su archivo nombrado, completo y sin truncar (contrato de entregable). Los estándares VIRF (C1–C6) viajan en el anclaje desde el Paso 0 (P4). Los pasos de entendimiento (A1, A4) miden manuales y código (.py/.ipynb) y son exhaustivos. El workflow entrega cuatro Excel troncales — 00_Diagnostico, 01_Control_de_datos, 02_Motor y 03_Impactos — y el entregable final es el Excel general Validacion_<codigo>.xlsx (Ámbito · Riesgo · Sustentación · Observaciones · Recomendaciones · Responsable/Fecha) más el Informe_Final.md con pantallazos de las fórmulas. Regla: sin fuente exacta, "No evidenciado" — nunca "Cumple".
